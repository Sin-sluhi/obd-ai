# OBD AI

Android-приложение для диагностики машины через обычный Bluetooth-адаптер ELM327
и последующей расшифровки ошибок нейросетью.

## Что умеет (v0.1)

- Подключение к ELM327 по Bluetooth Classic (три способа, для капризных клонов)
- Автоопределение протокола (CAN, K-line, J1850)
- Чтение статуса Check Engine, сохранённых и неподтверждённых ошибок (режимы 01, 03, 07)
- Чтение VIN (режим 09)
- 8 датчиков в реальном времени плюс напряжение сети
- Стирание ошибок (режим 04)
- Кнопка «Отчёт для ИИ»: копирует всё собранное в буфер вместе с промптом
- Консоль для ручных AT/OBD-команд

## Сборка

Собирается в GitHub Actions при каждом пуше. Готовый debug-APK лежит в
Releases под тегом `latest`. Локально: `gradle assembleDebug` (нужен JDK 17 и Android SDK 34).

Debug-сборка подписывается временным ключом, поэтому перед установкой новой
версии старую придётся удалить.

## Как пользоваться

1. Воткнуть адаптер в OBD-разъём, включить зажигание.
2. Спарить адаптер в настройках Bluetooth телефона (PIN обычно 1234 или 0000).
3. В приложении нажать «Подключить» и выбрать адаптер.

## Структура

- `ObdDecoder.kt` — разбор сырых ответов ELM327, без зависимостей от Android
- `Elm327.kt` — Bluetooth-соединение и обмен командами с адаптером
- `MainActivity.kt` — экран приложения
