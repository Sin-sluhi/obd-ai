# OBD AI

Android-приложение для диагностики машины через обычный Bluetooth-адаптер ELM327
с расшифровкой ошибок нейросетью на основе опыта владельцев с форумов.

## Что умеет (v0.2)

- Тёмный интерфейс «приборная панель ночью», акцентный цвет на выбор
- Одна кнопка «Проверить машину»: читает Check Engine, ошибки (режимы 03 и 07), VIN, датчики,
  отправляет всё в Claude и показывает вердикт: можно ли ехать, что сломано, что делать, сколько стоит
- Перед вердиктом нейронка через веб-поиск смотрит на drive2.ru и drom.ru, как владельцы такой же
  машины решали каждую ошибку, и показывает это в карточке со ссылками
- Экран датчиков в реальном времени: обороты, температура, напряжение, коррекции топлива
- История проверок, «Поделиться», «Найти сервис рядом», стирание ошибок
- Без ключа API: названия ошибок из встроенного справочника и кнопка «Спросить Claude»
  (отчёт копируется, открывается приложение Claude)
- Демо-режим с выдуманной машиной, чтобы посмотреть приложение до покупки адаптера
- Консоль для ручных AT/OBD-команд и лог обмена с адаптером

## Сборка

Собирается в GitHub Actions при каждом пуше. Готовый debug-APK лежит в
Releases под тегом `latest`. Локально: `gradle assembleDebug` (JDK 17, Android SDK 35).

Debug-сборка подписывается временным ключом, поэтому перед установкой новой
версии старую придётся удалить.

## Как пользоваться

1. Воткнуть адаптер в OBD-разъём, включить зажигание.
2. Спарить адаптер в настройках Bluetooth телефона (PIN обычно 1234 или 0000).
3. В приложении нажать на статус адаптера, выбрать его, затем «Проверить машину».
4. Для разбора прямо в приложении: Настройки → ключ Claude API (console.anthropic.com).

## Структура

- `ObdDecoder.kt` — разбор сырых ответов ELM327, без зависимостей от Android
- `Elm327.kt` — Bluetooth-соединение и обмен командами с адаптером
- `ObdLink.kt` — общий интерфейс источника данных и демо-машина
- `AiClient.kt` — два вызова Claude API: поиск по форумам и строгий JSON-вердикт
- `AppState.kt` — состояние приложения, фоновые задачи, история
- `ui/Theme.kt`, `ui/Screens.kt` — дизайн-система и экраны на Jetpack Compose
- `MainActivity.kt` — навигация, Bluetooth-разрешения, системные действия
