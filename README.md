# OBD AI

Android-приложение для диагностики машины через обычный Bluetooth-адаптер ELM327
с расшифровкой ошибок нейросетью на основе опыта владельцев с форумов.

## Что умеет (v0.3)

- Тёмный интерфейс «приборная панель ночью», акцентный цвет на выбор
- Одна кнопка «Проверить машину»: читает Check Engine, ошибки (режимы 03, 07, 0A), VIN, датчики,
  отправляет всё нейросети и показывает вердикт: можно ли ехать, что сломано, что делать, сколько стоит
- Перед вердиктом нейросеть ищет на drive2.ru и drom.ru, как владельцы такой же машины решали
  каждую ошибку, и показывает это в карточке со ссылками
- Провайдеры разбора: Groq (по умолчанию, бесплатно, встроенный поиск), YandexGPT, OpenRouter,
  Mistral, Claude или свой OpenAI-совместимый сервер; для провайдеров без поиска приложение
  само ищет записи на форумах
- Экран датчиков в реальном времени: обороты, температура, напряжение, коррекции топлива
- История проверок, «Поделиться», «Найти сервис рядом», стирание ошибок
- Пользователь не видит ни ключей, ни моделей: всё настраивается секретами сборки
- Режим разработчика (7 нажатий на версию в настройках): выбор провайдера, ключ, модель,
  демо-машина, консоль и лог адаптера
- Шрифты Unbounded / Manrope / JetBrains Mono, объёмные карточки, свечение акцента

## Сборка

Собирается в GitHub Actions при каждом пуше. Готовый debug-APK лежит в
Releases под тегом `latest`. Локально: `gradle assembleDebug` (JDK 17, Android SDK 35).

Debug-сборка подписывается временным ключом, поэтому перед установкой новой
версии старую придётся удалить.

## Как пользоваться

1. Воткнуть адаптер в OBD-разъём, включить зажигание.
2. Спарить адаптер в настройках Bluetooth телефона (PIN обычно 1234 или 0000).
3. В приложении нажать на статус адаптера, выбрать его, затем «Проверить машину».
4. Разбор работает сам, если в сборку встроен ключ (см. ниже) или ключ задан в режиме разработчика.

## Ключ нейросети в сборке

В репозитории GitHub: Settings → Secrets and variables → Actions.
- секрет `AI_API_KEY` — ключ провайдера (для Groq: console.groq.com → API Keys)
- переменная `AI_PROVIDER` — `groq` (по умолчанию), `yandex`, `openrouter`, `mistral`, `anthropic`
- переменная `AI_MODEL` — необязательно, имя модели вместо стандартной

После добавления секрета перезапусти сборку: ключ попадёт внутрь APK, и пользователю ничего вводить не нужно.

## Структура

- `ObdDecoder.kt` — разбор сырых ответов ELM327, без зависимостей от Android
- `Elm327.kt` — Bluetooth-соединение и обмен командами с адаптером
- `ObdLink.kt` — общий интерфейс источника данных и демо-машина
- `AiConfig.kt` — провайдеры и их настройки
- `OpenAiClient.kt` — вызов любого OpenAI-совместимого API (Groq, Yandex, OpenRouter, Mistral, свой)
- `ForumSearch.kt` — свой поиск записей на drive2/drom для провайдеров без встроенного поиска
- `AiClient.kt` — оркестратор разбора: Groq одним вызовом, остальные в два этапа, Anthropic через web_search
- `AppState.kt` — состояние приложения, фоновые задачи, история
- `ui/Theme.kt`, `ui/Screens.kt` — дизайн-система и экраны на Jetpack Compose
- `MainActivity.kt` — навигация, Bluetooth-разрешения, системные действия
