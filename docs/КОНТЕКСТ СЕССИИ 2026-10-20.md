## Сделано
1. **Логи сами, шаг 1** — автоотправка лога каждой проверки на сервер (без согласия, выключатель в настройках), VIN-серийник

2. **Перевод 7 094 SAE-кодов** на русский (`tools/dtc/open/ru/sae_*.tsv`).
3. **Шаг 2 — лестница повторов** (78 → слушать `3E 80`; 31 → маски; 11/12/31 → `10 03`; поздний `59 02` на любой ступеньке) и
   **статус UDS**: биты 4/6 «тест не завершён» — не коды (у Grandeur было 208 ложных «кодов истории» из 216).
4. **Проверка без возвращений**: память способа на блок (`EcuAddr.rung`), второй круг для непрочитанных, профиль модели с сервера
   (`/api/profile`), живой экран проверки (`CheckLive`), уведомление «Проверка готова», кнопка Обиди «Связь с разработчиком»
   (`dev.py`, раздел в админке), приборы без наложений, «Ищу блоки… найдено N» вместо «247 блоков», демо — только по желанию
   (ссылка на главной, выбор адаптера, настройки).
5. **ТагАЗ**: WMI X7M = Hyundai (было SsangYong).
6. **Лог Nissan без VIN (20.10)**: марка по набору блоков, коды шасси Nissan C1101–C1609, двигатель через OBD не «не разобран»,
   нейронка через сервер при «Connection reset» (`ai_relay.py`), KWP 13/17 (не проверено), 06A1 с паузой. Сервер перезапущен.
7. **Google Play — сделано лишнее** (владелец просил только объяснить, см. ниже): `68873a6` — релизный AAB тем же ключом в CI,

   `site/privacy.html`, `docs/play/GOOGLE PLAY.md`. Сборка зелёная. Ничего не откатывал — решение за владельцем
